# 皮影戏（shadowpuppet）

- **实现**：`lib/shadowpuppet.py` · `ShadowPuppet`
- **范例**：`examples/shadowpuppet_cuju.py` 蹴鞠 · Cuju by Lamplight（油灯从背后照亮的琥珀色幕布，前面是雕花戏台：回纹浮雕横楣、红漆金字牌匾「蹴鞠」、透空回纹挂落、两角镂空花牙子、两盏红灯笼；幕上是雕空、透明染色的驴皮：牌楼式球门（瓦顶飞檐、鸱吻、窗棂网、红边风流眼）、底部回纹装饰带、四个关节人偶。红方球头刚起脚，一条腿踢得老高，同伴一手高一手低、提膝亮相；青方一个跳起扑球（离幕一点，边缘发软、成双影），一个指着球；鞠正卡在风流眼里；「球头」「骁色」两块小牌挂在线上。人偶是阳刻空脸或阴刻红脸、雉翎盔或三叉冠、云肩护心镜鱼鳞甲、厚底靴，皮叠在一起处更深，关节有线结，操纵杆从领口和手上垂下去；`--stages` 出 60 个阶段，全是真运动：点灯、横楣落下、灯笼晃着亮起、球门升起、人从侧幕滑进来由虚变实、传球、起脚、亮相、小牌落下）
- **耗时**：约 7 秒（成品）/ 约 27 秒（含阶段）
- **内部构成**：皮影戏（油灯照亮的幕布、两个灯芯；按光密度叠加的透明染色驴皮：剪、染、描边、打孔、九种镂空纹样；关节树人偶、线结、操纵杆；离幕虚化与双影；标准人偶（阳刻空脸 / 阴刻脸、雉翎盔 / 三叉冠）；牌楼球门、鞠、底部回纹带、小牌；雕花戏台、红漆金字牌匾、灯笼）

## 何时选用

中国传统与民间艺术、节庆（元宵、庙会、过年）、戏曲和民间故事、古代体育与游戏（蹴鞠、赛龙舟、舞狮）、「一场好戏」式的小叙事（登场—交手—亮相），讲解片里的「历史 / 传统 / 一场比赛的高光时刻」页，要人物有动作又不能用真人 → 皮影戏（要黑纸剪的侧影小像用剪影；要彩纸剪贴的童趣用剪纸拼贴；要山水留白用水墨）；

## 接口速查

```python
import sys; sys.path.insert(0, "<本skill>/lib")
from core import spline, curve, blob_pts, fbm1d, blur, polygon_mask  # 公共工具，按需取用
from shadowpuppet import ShadowPuppet
```

- 思路：幕布上看到的每一点都是透过来的灯光。幕布是一盏油灯从背后照亮的布：灯后面那一块最亮、最淡，往外越来越深的琥珀色，带纱线粗节、一两道折痕和暗角。人偶是刮薄上油的驴皮，半透明、染透明色：每块皮（`Leather`）存覆盖率和每个通道的光密度，到达眼睛的是 灯光 × exp(−密度)，所以朱红、青绿、赭黄透亮，黑色几乎不透光，两块皮叠在一起密度相加、自然变深（关节、远侧手脚压在身上都这样），叠放顺序不影响结果。人偶贴在幕上（`d = 0`）清楚；`d` 越大影子越大越虚，又因为灯有两个灯芯，分成两个错开的影，就是「没贴紧」的那种软的双边。操纵杆在绑的地方清楚，越往下越离幕、越虚。最后整幅加一点辉光、一条柔肩的色调曲线、暗角和细颗粒；雕花戏台和灯笼在幕前，被幕布溢出的光照亮
- 构造：`ShadowPuppet(W, H, seed, keep_stages=True, stages_dir=None)`（给了 `stages_dir`，`stage()` 当场写 PNG）；`screen(colour, edge, hot, weave, folds)` 幕布（`hot` = 灯在幕后的位置）；`lamp(level, radius, flicker)` 灯：亮度、光晕铺开到几成（0.1 = 刚点着的一小团）、闪一下（±）；`proscenium(plaque='蹴鞠', top=150, valance=54, side=64, sill=80, bracket=170, plaque_w=420)` 戏台：回纹浮雕横楣 + 中间红漆金字牌匾、透空回纹挂落、两角镂空花牙子、立柱、台口，并把幕布开口设成框内；`frame(dy, alpha)` 横楣这一组的位姿（动图里从上面落下来，灯笼跟着动）；`lantern(x, top, r, drop, tassel, lit, swing)` 红纸灯笼：竹骨、里面的烛光、黑漆金边帽、金结红穗、一圈暖光晕，`set(lit, swing, shown)`
- 皮 `Leather(x0, y0, x1, y1, scale, ss=3, seed)`（坐标是设计单位，× scale 是像素，原点就是枢轴；`sp.leather(...)` 自动给种子）：`fill(形状, 染料)` 剪出 / 贴上一块皮，`dye(形状, 染料)` 给已有的皮换色，`edge(宽)` 沿剪边描黑，`contour(区域, 宽)` 给一块区域描边，`punch(形状, rim)` 打孔（孔边一圈墨），`line(点, 宽)` 一条皮线，`carve(点, 宽)` 刻一道缝，`pattern(区域, 纹样, 大小, angle, margin, origin)` 在区域里镂空，四周留 margin 宽的实皮：`dots` 圆点、`rings` 圆环、`flower` 梅花、`coins` 铜钱、`scales` 鱼鳞甲、`cloud` 如意云头、`lattice` 方格（angle=45 是斜格）、`stripes` 条孔、`ice` 冰裂纹；圆点类（dots / rings / flower / coins）转 `angle=90` 时，窄条里只剩居中的一列（门柱就是这样）；形状工具 `poly ellipse ring stroke ribbon(宽度渐变的带) text(竖排字) below / above / left_of / right_of inset grow`；`finish()` 把皮厚不匀（30 px 斑驳、90 px 色块、细纤维）算进去，变成「每个通道挡掉多少光」。形状可以给点列，也可以给同尺寸的遮罩
- 人偶 `Puppet`：`add(名字, 皮, parent, joint)` 一棵关节树（子件的枢轴挂在父件的 joint 上，关节处一颗线结；先加父件）；`pose(**角度)`：角度按「人朝右时逆时针」量，垂下的手脚 +90 是向前平伸，头 +10 是抬头，躯干 +6 是往后仰；`set(x, y, rot, d, flip, alpha)`；`state()` / `load(st)` / `Puppet.tween(a, b, t)` 存取和插值整套姿态（动图逐帧用）；`rod(部件, 点, lean, width)` 操纵杆；`ground(地板 y, [部件])` 让最低的鞋底落在地上；`away[部件] = 距离` 让某一件单独离幕；`point(部件, 点)` 部件上一点的画布坐标
- `figure(robe, trim, accent, trousers, face, skin, facedye, headdress, plume, pom, pattern, hands, scale)` 出一个标准人偶（朝右，`flip=True` 朝左）：`pelvis` 短裙腰带为根，`torso` 云肩、护心镜、鱼鳞甲、腰带，`head` 侧脸（`face='hollow'` 阳刻空脸：脸挖空，只留侧脸线、一只长眼、一道长眉；`face='solid'` 阴刻：脸留着 `facedye` 染的皮，五官刻空），`arm_f / arm_b` 上臂（只有近侧带护肩花），`fore_f / fore_b` 小臂和袖口，`hand_f / hand_b`（`'open'` / `'fist'`），`thigh_f / thigh_b`，`shin_f / shin_b` 绑腿和厚底靴；头饰 `'plume'` 盔 + 两根带黑横斑的雉翎、`'crown'` 三叉冠 + 绒球 + 侧穗、`'bun'` 发髻飘带；scale 1 时鞋底到盔顶约 520 px
- 道具（一块皮的 prop，可以像人偶一样移动、离幕）：`gate(w, h, net_h, eye, eye_r, post, beam, roof, net, trim)` 牌楼式球门：立柱（一列铜钱孔）、额枋、瓦顶飞檐、鸱吻卷、宝珠，窗棂网和红边风流眼，枢轴在地面中点；`ball(r)` 鞠：六道缝线、红芯、每瓣一个梭形孔；`border(y0, y1, dye, trim)` 底部装饰带（圆点条、镂空回纹带、黑边，画布坐标，放在 0, 0）；`nameplate(text, dye, size, string)` 挂在线上的竖排小牌（枢轴在线头）；自己做的：`sp.prop(皮)`；`place(p, x, y, **kw)` 放上幕布或更新，`hide(p)`
- 字体：`plaque` / `label`（牌匾、小牌）：魏碑（macOS 按需下载的字体）→ 隶变 → 楷体 → 宋体，Linux 用 Noto Serif CJK，Windows 用华文新魏 / 楷体；可用 `INKPAINT_FONT_SHADOWPUPPET_PLAQUE` / `_LABEL` 指定
- 染料 `DYES`：plain red crimson teal green ochre yellow blue brown pink black；色板常量 `SCREEN SCREEN_EDGE HIDE WOOD LACQUER GOLD SPILL ROD LAMPS`；`render()`、`composite()`、`stage(name)`、`save(path, stages_dir)`；`save('x.jpg')` 默认 quality 88、4:4:4 色度

## 毛病清单（都真实出现过）

| 问题 | 改法 |
|---|---|
| 幕布像一面白墙，颜色像印在纸上，不发光 | 光晕衰减太缓、热点太白：光晕半径缩到 0.47W × 0.64H，底亮度 0.20 → 0.10，热点压成琥珀 (1, 0.75, 0.37)、边缘深橙；色调曲线用柔肩，亮处只微微溢出 |
| 衣服像渔网袜，一身全是小孔 | 镂空太密：大面积的袍子留实色，纹样只放在一段里（裙上云头 26、胸前鱼鳞 17、袖子一段云头），裤子只在外侧缝一列圆点；画布上一个纹样单元至少约 12 px |
| 人偶细长、脖子长、头小 | 躯干加宽到约 90，腿缩短（大腿 100、小腿到鞋底 116），头单独放大 1.15 倍，脖子关节下移 7 |
| 两肩一团黑 | 两只上臂都带护肩花，叠在云肩上：只让近侧那只带 |
| 举起来的手臂盖住了脸 | 侧身时肩在头的正下方，近侧手臂抬过约 140° 就从脸前过：要高举就举远侧那只（向后上方），近侧手臂斜向前上（130–147°）；亮相用一手高（远侧向后上）一手低（近侧向前下）加提膝 |
| 离幕一点（d = 0.05）的人整个糊了 | 虚化长得太快、双影分得太小：σ = 0.5 + 16d，放大 1 + 0.30d（两个灯芯的影子分开约 5 px），得到一个清楚的影加一条软的双边，而不是失焦 |
| 挂落和花牙子被照成一片橙色 | 溢光拿整块幕布算，木头后面的也算上了：只用露出来的幕布（× (1 − 木头遮罩)），木头正面是暗的，挨着亮处的边才有一圈暖光 |
| 花牙子只是几根细线 | 改成一块四分之一圆的雕板，挖空中间、留宽边，里面三个涡卷 |
| 鞠放进风流眼里像一朵淡花 | 太淡、孔太多：实心赭黄、红芯、六道黑缝线、每瓣一个梭形孔，半径 28 |
| 两个红方人物挤在一起（翎子扫到同伴头上、同伴的手搭在球头背上） | 翎子给后仰踢球的那个，同伴戴三叉冠，左右拉开到 262 / 612；踢球的人往左让，脚停在左门柱左边 |
| 动图里鲜红和绿裤子被量化成土红、灰绿 | 人偶最后才出场，均匀取样把这些颜色平均掉了：成品取样 ×8，再只从最后几帧的饱和色和冷色（青、绿）里切 105 色，最后 6 轮 k-means，末帧 p99 误差 34 → 16 |
| 结尾灯闪三下多出 360 KB | 每闪一下整片幕布都变，要整帧重发：只暗一下（7%）；点灯也从 7 帧减到 5 帧 |
| 画戏台时峰值内存 1.2 GB | 浮雕打光在整张画布上算：只在横楣一条、两根柱子、台口一条上分段算，远处溢光用半分辨率，球门和底带用 2 倍超采样；峰值约 0.8 GB（出阶段约 0.9 GB） |
