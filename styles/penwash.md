# 钢笔淡彩（penwash）

- **实现**：`lib/penwash.py` · `PenWash`
- **范例**：`examples/penwash_neighbours.py` 街角速写 · Sketchbook Neighbours（橡木桌上并排四张冷压水彩小卡，一张一个街坊在做一件小事：吹着口哨的邮差，钴蓝帽子和外套，挎包塞得太满，两封信从背后逃出去扑扇着飞走；戴超大圆眼镜的奶奶给花盆浇水，猫却钻进了盆里，水滴正落在它两耳之间（眯眼、爪子扒着盆沿），真正的那朵红花在旁边干等；踩滑板车的小孩，钴蓝头盔大了两号、压到眉毛，吐着舌头，膝盖贴着创可贴，身后速度线和尘土；圆滚滚的面包师戴高高的白帽子，抱着一根比他还长的法棍，法棍从手绘边框里戳出去，一只麻雀落在尖上啄；针管笔线条抖、出头、不闭合、偶尔描两遍，淡彩错位出线、在线里留白缝、干边、颗粒，腮红湿中湿，不铺满的背景色块绕开人物留白边，白色水粉高光；卡片有阴影和受光的切边，旁边放着一支针管笔、一支水笔（透明杆里的水和气泡、染了颜色的尼龙笔尖）和水笔的笔帽；`--stages` 出 9 个阶段：空桌、白卡、两批墨线、两遍淡彩、背景色块、高光、放下笔）
- **耗时**：约 3 秒（成品）/ 约 6 秒（含阶段）
- **内部构成**：钢笔淡彩（冷压水彩小卡：受光纸纹、不直的切边；针管笔线：手抖、出头、不闭合、描两遍、按 z 遮挡断线；淡彩：错位出线与留白缝、游走的边、干边、颗粒、平刷条纹、湿中湿、起皱；不铺满的背景色块与白边；白色水粉；呆萌小人部件；橡木桌、卡片阴影、针管笔与透明水笔）

## 何时选用

人物小品、街坊邻居与日常小事（送信、浇花、骑车、买面包）、一组角色卡 / 人设卡、旅行和城市速写里「一个人在做一件小事」、轻松幽默的配图，讲解片里「一组用户 / 角色 / 团队成员」的介绍页 → 钢笔淡彩（要蓝铅笔稿、毛笔线和赛璐璐阴影的拟人小物用卡通手绘；要风景和花卉的大片晕染用水彩；要真的动起来的角色用绘本角色动画；要草稿纸上的随手涂鸦用圆珠笔涂鸦）；

- 思路：每张卡片是一张独立的冷压水彩纸（自己的缓冲区，按卡片坐标 = 画布像素、不转着画，内部 2 倍分辨率），拍照时才按位置和小角度放到桌上。纸：约 1 mm 的凸点（这里 2–4 px）叠在更缓的起伏上，按左上窗光打光；切边略不直、有毛边。墨线是针管笔：几乎等宽，每一笔重采样后加低频手抖和一点颤动，线宽 ±9% 漂移，落笔处一个小墨点，部分笔画收尾一甩变细；画得快，闭合形状由 1–3 笔组成，接口处要么停早留缺口、要么冲过头沿切线出头，方框的角各画各的、相互出头，偶尔一段再描一遍、偏 1–2.5 px；墨按比尔定律光密度叠加，纸纹最深的谷里略漏白；部件按 z 遮挡，被前面部件盖住的轮廓线自动断开。淡彩（墨干后上）先算「本来要涂的区域」（部件减去前面的部件），再像手快那样涂：整块错位 2–5 px（一边出线、另一边在线里留白缝）；边缘在模糊副本上用游走的阈值重新取（负的出线、正的回缩，另有成片回缩的白缝），利落但抖、顺着纸纹；干边（水干时颜料跑到边上）；颗粒（颜料沉进纸纹的谷）；平刷条纹；浓淡斑驳；可选干笔飞白；湿中湿 `bleed`（滴进还湿的色块、软边、停在湿边）；打湿的地方纸面起皱。颜料也按光密度叠加，相叠变深、混色。背景色块是不铺满卡片的粗糙平涂矩形，绕开人物留几 px 白边。白色水粉最后上、不透明
- 构造：`PenWash(W, H, seed, ss=2, keep_stages=True, stages_dir=None)`；`table(kind='oak'|'pale'|'walnut'|'linen', plank=176)` 桌面（橡木板：带「山纹」拱形的年轮、导管、板缝和拼接缝、缎面光泽）；`card(cx, cy, w, h, rot, tone, corner, tooth, seed)` 放一张白卡并设为当前卡（rot 是顺时针度数），`use(card)` 切换；之后的绘制都画在当前卡上（也可以传 `card=`）
- 部件（墨线在 `ink()` 时才画）：`part(pts, z, ink=True, strokes=None, corners=False, smooth=True, width, reserve=True, nseg)` 一个区域加它的轮廓（`strokes` 改成只描给定的几段开放路径；`corners` 在角上拆成相互出头的直线；`reserve=False` 时背景色块不绕开它；`nseg` 指定闭合轮廓分几笔）；`limb(pts, w0, w1, z, caps=(False, True))` 袖子、腿、背带（只描两侧和指定的端头）；`stroke(pts, z, width, closed, smooth, corners, wobble, over=(0, 3), double, flick, nseg)` 单独一笔（被 z 更高的部件挡住的部分不画）；`lines(paths, …)`；`dot(x, y, r, z)` 点出来的眼睛；`ink()` 给当前卡上所有待画的笔画上墨
- 脸和小件：`glasses(cx, cy, r, gap, z, temple=(x, y))` 一副大圆眼镜（两片镜片是部件，后面的肤色涂到镜框就停、镜片里留白），返回两片镜片；`brows(paths)`；`tufts(x, y, n, length, spread, angle)` 几根翘起的头发；`frame(x0, y0, x1, y1)` 手绘边框（四边各一笔、角上出头）；`ground(x0, x1, y)` 两笔粗地线；`signature(x, y, size)` 角上的小螺旋签名
- 形状（静态方法，卡片坐标）：`PenWash.oval(cx, cy, rx, ry, rot, egg, wob)`（`egg` > 0 是下宽的大头）、`rrect`、`box(cx, cy, w, h, rot)`、`turn(pts, cx, cy, deg)`、`smooth(pts, closed)`、`tube(pts, w0, w1)` → (轮廓, [左边, 右边, 末端, 起端])、`hand(x, y, angle, size, kind='mitten'|'open'|'fist', flip)` → (轮廓, 指缝线)
- 颜料：`wash(target, colour, strength, shift, slip=(2, 4.8), warp=1.6, gaps=2.2, soft=2.2, edge=0.35, gran=0.14, streak=0.08, angle, var=0.13, dry)`，target 是部件、部件列表、点列或 `('mask', sl, m)`；区域等效半径小于 16 px 时错位、白缝和抖动按比例缩小；`bleed(target, x, y, r, colour, strength)` 湿中湿（腮红、面包烤色）；`background_block(x0, y0, x1, y1, colour, strength, rough, corner, halo, angle, edge, streak, dry)`；`spatter(colour, n, box, size)` 甩上去的颜料点；`highlight(pts, width, alpha)`、`glint(x, y, r)` 白色水粉；颜色用 `PAINTS` 里的名字（coral red pink rose peach skin tan ochre yellow brown terracotta teal mint sage green cobalt sky bluegrey grey warmgrey black lilac）或 '#rrggbb'
- 桌上的道具：`pen(x, y, angle, length=430, r=10.5, cap=True)` 针管笔（笔尖在 (x, y)、笔身朝 angle 度：纤维笔尖、金属套管、灰色锥头、哑光笔杆上印着线宽、套在尾部的亮面笔帽和笔夹）；`water_brush(x, y, angle, length=320, r=12, stain='teal', cap=(x, y, angle))` 水笔（尼龙笔尖、尖上染一点颜料、螺纹握把、微雾的透明水杆按圆柱折射下面的东西、尾部气泡；`cap` 另放一个透明笔帽）；都按圆柱打光、带投影（透明部分影子浅、有一点焦散）。比例：卡片约 9 cm 宽时，针管笔比卡片还长（范例 640 px、r 16），水笔 600 px、r 24
- 常量 `PAINTS INK PAPER WOODS LINEN SHADOW`；`render()`、`composite()`、`stage(name)`、`save(path, stages_dir)`；`save('x.jpg')` 默认 quality 88、4:4:4 色度；笔杆上的字用 core 的 sans_bold（可用 `INKPAINT_FONT_SANS_BOLD` 指定）

## 毛病清单（都真实出现过）

| 问题 | 改法 |
|---|---|
| 卡片像拉毛墙，淡彩像彩铅一粒一粒 | 纸纹受光 0.42 → 0.20；淡彩颗粒 0.35 → 0.14、笔刷条纹 0.18 → 0.08（背景色块 0.2 / 0.12）。颗粒和条纹只要隐约看得见 |
| 鼻子、舌头、面包屑变成一个个白圈 | 小区域也照样错位 3–5 px、留 2 px 白缝，颜色就被挤没了：`wash()` 按区域等效半径缩放错位、留白缝和边缘抖动（小于 16 px 按比例缩小，最低 0.22 倍） |
| 胡子下面吹口哨的小「o」读成字母 p | 小圆圈挂在胡子下面就是一个字母：删掉，口哨只靠旁边两个音符 |
| 红色圆顶头盔读成毒蘑菇 | 红顶 + 白通风孔 + 一块大高光就是蘑菇：换钴蓝头盔、深色通风槽、珊瑚色条纹，不加大高光；帽檐压到眉毛，两只眼睛从下面露出来，「头盔太大」才看得出来 |
| 浇水壶像烧水壶 | 壶身前倾约 14°，长壶嘴从壶底前侧斜伸出去，头上一个莲蓬头带几个小孔，提手从顶上跨过去 |
| 白围裙椭圆像雪人肚子；换成蓝袖白前胸又像企鹅 | 白厨师服的圆身子 + 窄一点的钴蓝背带围裙；围裙口袋只描线，做成不上色的部件会变成白洞，把围裙变成「6」字 |
| 小孩的第二只眼、鼻子、舌头落在脸的轮廓外 | 五官收进头的轮廓里，只让鼻子在轮廓边上鼓出一点；车把立杆放在脸的前方，不能从脸上穿过 |
| 透明水杆没有影子，像浮在桌上，还有橙色光斑 | 透明部分影子密度 0.62（实心是 1），焦散只提亮 0.10；杆身加一点雾面（+0.08）才像塑料不像玻璃 |
| 木纹像贴膜地板，中间突然断一截 | 每块板单独生成，加 1–2 组「山纹」拱形年轮；不要用 `np.roll` 挪纹理（卷绕处会断开），拼接缝右边换一块新板 |
| 笔太小，下面三分之一桌面空着 | 按真实比例：卡片约 9 cm 宽时，针管笔比卡片还长（640 px、r 16），水笔 600 px、r 24 |
| 动图里淡蓝、灰绿背景块变成灰青和米色，黄衣服发橙 | 橡木桌本身就是饱和色，「饱和像素 ×5」把色位都给了木头：56 色只从空桌面切，198 色只从和空桌面不同的像素切；末帧 p99 误差 35 → 23 |
