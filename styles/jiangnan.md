# 江南园林（jiangnan）

- **实现**：`lib/jiangnan.py` · `JiangnanGarden`
- **范例**：`examples/jiangnan_spring_water.py` 春水园林 · Spring Water Garden（一幅横幅的江南园林春景，从前景的花枝和柳丝之间望进去：画面中间是一池碧绿的春水，岸上的一切都倒映在里面，更柔、更暗，带涟漪和细竖纹；一座带镂空石栏板的九曲石桥折了三折，穿过水面通向一道粉墙，墙上的月洞门里露出另一个洒满阳光的小院（竹子、粉色花树、一块湖石、远处又一道白墙），旁边一扇冰裂纹漏窗，墙上落着叶影；粉墙旁是一座临水茶榭，黛瓦歇山顶、翼角高高翘起、脊头卷起，翡翠绿的槅扇门和灯笼锦窗、檐下挂落、一对红灯笼、一块写着「听雨」的小匾，台基上几盆花；茶榭右边一棵开满白花的树下，一条小木船系在石阶边；左岸一棵大垂柳，墙后一棵层层托盘的松树和一片深浅不一的树冠，再后面是雾里的青山；近处水面上一丛丛睡莲叶和几朵粉色睡莲，一只白鹭站在水中的石头上，另一只从松树前掠过；前景左下是深绿的灌木、白色小花和弯弯的鸢尾叶，右下一丛粉色杜鹃，左上垂下几缕近处的柳丝，右上一枝粉色花枝，花瓣在空中飘、在水面上漂；右下角一方小红印「春水」；照风景插画家的顺序从后往前画：天空和远山、远树和雾、建筑、对岸的园子、水和倒影、桥和船、睡莲和白鹭、前景草木、垂挂的画框，最后是印章和收尾的柔化、光晕、颗粒；`--stages` 出 9 个阶段加成品：天空和远山、远树、建筑、对岸、水、桥和船、睡莲和白鹭、前景、画框）
- **耗时**：约 6 秒
- **内部构成**：江南园林（叶形小笔触的 id 图光栅化：Pillow 按序号填多边形、numpy 查色表、2 倍超采样；按团块穹顶光照取色的树冠：暗底、穿出轮廓的叶、成簇的高光、最亮的几笔；花簇按明暗排序的繁花树、五瓣花的近景花枝；一绺绺细枝的垂柳、托盘松、弯曲的鸢尾叶；网格反求 (u, v) 的歇山瓦顶：筒瓦板瓦、瓦当滴水、飞檐翼角、卷脊头、檐下阴影；粉墙、叶影、方格 / 灯笼锦 / 冰裂纹槅扇、挂落、月洞门和漏窗、石作、台阶、针孔相机投影的九曲桥；湖面、按岸线镜像的倒影、自带倒影的桥船白鹭、横向笔触、涟漪和细竖纹、睡莲；红灯笼、匾额、小红印；柔化、光晕、颗粒）

## 何时选用

中国古典园林、江南春景、亭台楼阁和水、旅行与城市文化里的「园林 / 古镇 / 春天」，节气和节日（春分、清明、谷雨）的配图和海报，要繁茂、细腻、一眼就是「精心画出来的插画」的风景，讲解片里的「中国传统 / 生活美学 / 春天」页 → 江南园林（要留白的写意山水用水墨；要大片松散的晕染用水彩；要赛璐璐天空和夏日少年感用日本动漫；要木版套色和海浪用浮世绘；要皮影人物的一场戏用皮影戏）；

## 接口速查

```python
import sys; sys.path.insert(0, "<本skill>/lib")
from core import spline, curve, blob_pts, fbm1d, blur, polygon_mask  # 公共工具，按需取用
from jiangnan import JiangnanGarden
```

- 思路：照风景插画家的顺序从后往前画（天空 → 远山 → 雾 → 远树 → 屋后的树 → 建筑 → 对岸的园子 → 水面和倒影 → 水上的东西 → 前景 → 垂挂的画框 → 印章），不透明的颜料盖住后面的，画的顺序就是遮挡关系。
  - 空气透视：每个画法都有 `far`（0 近 – 1 很远），越远颜色越往雾色（淡青绿）靠、对比越低；深度层之间用 `haze()` 铺一道雾带，最浓处在山脚。
  - 笔触：一笔就是一个小多边形（尖叶、圆花瓣、剑形叶、圆点），各有大小、角度和颜色。成千上万笔一次画完：Pillow 把每个多边形按序号填进 2 倍超采样的整数 id 图（序号就是先后，后画的盖住先画的），numpy 按 id 查颜色和透明度表，再缩回 1 倍，边缘都有抗锯齿，一笔不到 1 微秒；颜料里叠一层固定的细画布纹理，明暗差几个百分点。
  - 光：太阳在左上、略靠前。树冠是一组团块（椭圆，排在后面的在前）；每一笔先找到自己落在哪个团块上（包含它的最前面那个），把团块当穹顶：法线给漫射，整团越往下越暗，再加低频噪声打散。这个 0–1 的值从一条混好的绿色色阶里取色（深青绿的芯 → 中绿 → 黄绿 → 淡的阳光绿）。
  - 树冠照水粉画家的画法：暗底（团块的芯 + 1.7 倍大的暗叶，底色的边缘也是叶子）→ 满冠中暗的叶 → 穿出轮廓的叶 → 受光值高的地方一簇簇（5–14 片）亮叶 → 最亮的几笔。叶尖朝外、微微下垂；近景灌木用 `veins` 给亮叶加一道浅叶脉。托盘松是同一个模型：歪扭的树干加几层扁平的针叶盘，针叶用很细的叶片、几乎不下垂。
  - 繁花树：枝干、笔触暗底（暗花瓣 + 深绿叶，不是一块平涂）、细枝、几片嫩叶，然后几百个花簇按明暗排序（亮的压在暗的上面），簇里朝阳的花瓣更白，枝条从簇间的缝里露出来；`blossom_branch()` 是近景花枝：一朵朵五瓣花、花蕊、花苞和嫩叶。
  - 垂柳：树干和几根弯枝先画，再用一层垂叶的树冠盖住枝；几百上千根柳丝一绺一绺（同一处垂下 3–9 根，绺与绺之间留缝），从枝上或树冠里出来，先往外拱一点再垂下，带一点摆；每根是发丝细的茎，两侧随机地挂着小窄叶，略张开、朝下。从后往前画（后排暗、偏蓝，前排亮、偏黄），受光一侧和梢头的新叶更亮。
  - 屋顶：正面看的歇山顶是一张曲面 S(u, v)（u 横向 −1..1，v 从正脊 0 到檐口 1）：上陡下缓（举折，檐口一段被透视压扁），越往下越宽，翼角向外甩出，檐口两端急速起翘。曲面拆成小四边形网格画进 id 图，每个像素用两步牛顿迭代反求精确的 (u, v)，瓦就能解析地上色：筒瓦（左侧受光，旁边一道暗缝）和板瓦一行隔一行，每层瓦口一道亮边、下面一道阴影，每片瓦各有一点明暗，偶尔一片发绿；檐口一排瓦当和滴水，檐下是椽头和檐底，墙面上落一道檐影；正脊有镂空花脊和卷起的脊头，戗脊一直通到翘起的翼角尖。
  - 建筑：粉墙是平涂加低频斑驳、檐下雨渍、发绿的墙脚和一层淡笔触；`dapple()` 是树叶在受光面上投下的叶影（阈值噪声的冷色斑，离投影的树越近越重）。槅扇和窗（方格、斜格、灯笼锦、冰裂纹）在 3 倍图上画棂条，左上沿亮、右下沿暗，在里面的暗室或窗纸上投一点影；柱子是漆过的圆柱加柱础；灯笼是带骨的红色椭球，金色顶底和流苏；匾额是带框的木板和描金字；台基、台阶和桥都是一块块有缝的石头，每块各有明暗。九曲桥是真的几何：桥段、石板、桥墩、望柱、镂空栏板和扶手都经针孔相机（`camera()`、`project()`）投影，每个面按法线上色，背对镜头的面剔掉。
  - 水：湖面是碧绿的本色，远处映着天更淡。倒影是岸线以上的画面按岸线镜像，横向被细浪推开，竖向模糊（离岸越远越糊），压暗，并按菲涅尔越往近处越多地混进本色，所以和岸上的东西对得上，只是更柔、更暗。立在水里的东西自带倒影：桥把几何的高度取反再投影一遍，船和白鹭把自己那一层按水线翻下去。最后是从水面本身取色的横向笔触、淡淡的涟漪线（映天的亮、映岸的暗）和细竖纹。睡莲叶经相机躺在水面上（椭圆按 眼高 / 距离 压扁），带缺口、叶脉、亮的远边、暗的近半边和一点影子。
  - 收尾 `grain()`：轻微柔化、亮部一圈春天的光晕、暗部偏青、细颗粒、极淡的画布纹和竖纹；`seal()` 一方边缘磨损的小红印，白字。
- 构造：`JiangnanGarden(W, H, seed, keep_stages=True, stages_dir=None)`（总像素不超过 4096²）；`camera(horizon, eye, focal, cx)` 定湖面上的针孔相机，配 `project(X, Y, Z)`、`ground_y(Z)`、`depth_at(y)`、`px_per_m(Z)`。画布坐标是像素；世界坐标是米（X 向右、Y 从水面向上、Z 向远）。
- 底层：`dabs(xs, ys, length, width, colours, angle, shape='leaf'|'round'|'blade'|'dot', alpha, far)` 一次画很多笔（角度用弧度）；`stroke(path, w0, w1, colour)`；`fill(mask, colour, alpha)`；`poly(pts)`、`ellipse(cx, cy, rx, ry)` 返回画布大小的遮罩；`crown(cx, cy, w, h, n, size)` 生成团块 (cx, cy, rx, ry)；`with g.clipped(mask):` 只画在遮罩里（月洞门里的景）。
- 天空和远处：`sky(top, bottom, y1, clouds)`；`hills(ridge, base, colour, far)` 山脊样条、浮雕噪声打光、树冠凸起的轮廓、山脚渐隐；`haze(y0, y1, y2, colour, strength)` 从 y0 升到 y1、到 y2 消失的雾带。
- 草木：`foliage(clumps, ramp_='spring', leaf=(5, 9), density, far, light, droop, aspect, veins, edge, highlights)`；`blossom_tree(branches, clumps, kind='white'|'pink'|'azalea', petal, density, far, leaves, gaps)`，branches 是 [(path, w0, w1), …]；`blossom_branch(path, w0, w1, kind, flowers, spread, size)`；`willow(trunk, boughs, strands, length, ramp_, leaf, far, sway, crown, tips, gap, bundle, splay, aspect, crown_anchor)`；`pine(trunk, limbs, pads)`；`branch(path, w0, w1)`；`reeds(x0, x1, y 或 f(x), n, height, lean, width, bend)` 弯曲的剑形叶；`petals(region, n, kind, water)`；`rock(cx, cy, rx, ry)`；`pot(x, y, w, h, colour, band)` 返回盆口中心。
- 建筑：`wall(x0, y0, x1, y1, colour, stains, damp)`；`dapple(x0, y0, x1, y1, amount, scale, cover, falloff=(x, y, r), mask)`；`roof(cx, y_ridge, y_eave, ridge_w, eave_w, upturn, flare, rows, courses, ridge_h, soffit, shadow)` 返回曲面函数；`coping(x0, x1, y, h)` 墙头瓦；`column(x, y0, y1, w)`；`beam(x0, x1, y0, y1)`；`lattice(x0, y0, x1, y1, pattern='lantern'|'grid'|'diamond'|'ice', cell, bar, frame, back='interior'|'paper'|颜色|None, kind='window'|'door')`；`fretwork(x0, x1, y0, h)` 挂落；`round_window(cx, cy, r, ring, pattern 或 inside=函数(遮罩), ground, reveal)` 漏窗 / 月洞门；`stonework(x0, y0, x1, y1, course, block, damp)`；`steps(x0, x1, y, n, rise, tread, grow)`；`bridge(path=[(X, Z), …], width, deck, thick, rail, post, rails='both'|'rear'|'none', reflection)`；`lantern(x, y, h, cord)`；`plaque(cx, cy, w, h, text)`。
- 水：`lake(y0, y1, far_colour, near_colour, bank)`；`reflect(bank, strength, blur, ripple, darken, fresnel, src)`（`src` 传画水之前的画布）；`layer()` + `reflect_layer(before, axis, box)` 给船、白鹭这类东西单独做倒影；`ripples(box, n, light, dark, alpha, brush)`；`lily_pads(pads=[(X, Z, 半径米)], flowers=[(X, Z, 大小米)])`；`lotus(x, y, s)`；`boat(x0, x1, y, h)`；`egret(x, y, s, pose='stand'|'fly', facing)`。
- 收尾：`seal(x, y, w, h, text)`；`grain(amount)`；`render()`、`composite()`、`stage(name)`、`save(path, stages_dir)`；`save('x.jpg')` 默认 quality 88、4:4:4 色度。
- 颜色用 `PAINTS` 里的名字（sky sky_low haze cloud plaster coral jade jade_dark jade_light lacquer beam interior paper stone tile board gold wood lantern seal bark bark_light water water_deep water_far terracotta porcelain egret）或 '#rrggbb'；色阶用 `RAMPS` 里的名字（spring jade deep olive willow far white pink azalea tile stone rock pad）或自己给一串颜色；常量 `LIGHT`。

## 毛病清单（都真实出现过）

| 问题 | 改法 |
|---|---|
| 树冠是一团团带噪点的绿球（「西兰花」） | 每个团块当穹顶打光；暗底先画团块的芯，再画 1.7 倍大的暗叶（底色边缘也是叶子），叶片穿出轮廓，亮叶 5–14 片一簇、只落在受光值高的地方；团块 24 个、大小 0.15–0.34，轮廓才碎；屋后的树 far 0.3、更后一排 0.4–0.6，越远越蓝、越平 |
| 垂柳是一整片石灰绿的帘子 | 柳丝 3–9 根一绺，绺与绺之间留缝；叶子 3–5 px、宽只有长的 0.28；后排的绺暗、偏蓝，前排亮、偏黄，受光一侧再亮一点 |
| 柳树顶上露出几道细黑弧线，像伞骨 | 先画枝，再用一层垂叶的树冠盖住，三成柳丝从树冠里长出来，树冠顶上才不是一条硬线 |
| 近处的柳丝是一根根麻花辫 | 叶子严格左右交替，成了人字纹：改成随机挂在一侧，离茎张开 0.18–0.5 弧度，长短不一；只画 34 根，每根稀一点，叶片更瘦（宽 0.22） |
| 九曲桥是一排横在水上的灰栏杆 | 太近、太大、栏杆太高、望柱太密：起点退到 15 m，栏高 0.5 m，望柱 1.9 m 一根；眼高 3 m 时近侧栏杆会把桥面整个挡住，改成只留远侧栏杆（很多曲桥本来就只有一侧栏杆），石板和缝才看得见，折线才读得出来 |
| 桥面像一块漂在水上的薄板 | 桥板侧面和桥墩的法向算反了，朝向镜头的面被剔掉：法向改成 (−e_z, 0, e_x)，桥板厚度和桥墩才出来 |
| 石桥满是麻点，像花岗岩 | 画布纹理 0.07 → 0.025，每个面只做一点明暗抖动 |
| 水面竖纹太重，像在下雨 | 细竖纹 3.5% → 1.3%，竖向模糊 9 → 14 px；另加从水面本身取色的横向笔触，水才像画出来的 |
| 睡莲叶是一圈红边的卡通盘子 | 卷边露出红背的只留 12%，边更细；近半边压暗改成 alpha 0.45、内缘收到 0.55 / 0.3（不再是一圈内线），远边一道浅亮边；叶子按几丛分布，不铺满水面 |
| 白花树是一团紫灰色的棉花 | 平涂的暗底缩到团块的 0.55，改成偏绿的深色，再用暗花瓣和深绿叶的笔触打底；花簇数量 ×1.5、每簇 12–25 瓣，受光一侧的花瓣更白 |
| 粉色灌木里露出几块平涂的褐紫色大斑 | 平滑的椭圆暗底换成笔触暗底（45% 深绿叶 + 55% 暗花瓣），椭圆只留团块中心 |
| 窗格中间一块黑方块像个洞，换成窗纸后又像一块空白牌子 | 侧窗用糊纸的底；灯笼锦中间的空框缩到宽 40%、高 34% |
| 漏窗被柳丝挡住 | 挪到月洞门和茶榭之间那段墙上 |
| 屋顶一片死黑、看不出瓦 | 瓦的色阶提亮；筒瓦受光侧 0.6，瓦口亮边 +0.3、下面的阴影 −0.26，越往檐口越亮（反射天光） |
| 飞着的白鹭像一根白羽毛 | 翅膀改成宽、往后掠的形状，翼尖分出五根飞羽，远侧翅膀发灰，颈缩回去，腿拖在后面 |
| 远山被树全挡住，看不出层次 | 两层山脊抬高 40–70 px；山脚 60 px 渐隐（不然动图前几帧山脚是一条硬横线） |
| 对岸右边是一片发白的雾墙 | 补上岸边的灌木和小树，一直到水边 |
| 光是平的，看不出春天的太阳 | 墙上、台基上、桥上加叶影（阈值噪声的冷色斑，离投影的树越近越重；桥上用桥的遮罩限住，不压暗水面）；檐下阴影 0.42 → 0.5 |
| 所有树都一个样 | 墙后加一棵托盘松（针叶用细叶片、几乎不下垂）；前景加白色小花和弯曲、带受光边的鸢尾叶（原来是直挺挺的绿刺） |
| 墙和水面太干净，像矢量图 | 墙上叠一层淡笔触（alpha 0.6，明暗浮动 −3.5% 到 +2.5%）；收尾加轻微柔化、亮部光晕、暗部偏青 |
