# Lazy-loaded style guides

This directory contains one focused guide per style. `SKILL.md` is the startup router; load only the guide matching the selected style.

Each guide follows this contract:

- **Implementation** — module, class, and representative example.
- **When to use it** — routing cues.
- **API entry points** — inspect the module for exact signatures.
- **Quality checklist** — preserve the style’s material, layering, lighting, and output model.

The initial refactor keeps the implementation source as the authoritative API reference and gives each style a stable, portable documentation entry point.
