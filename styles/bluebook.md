# 蓝调绘本（bluebook）

- **实现**：`lib/bluebook.py` · `BlueBook`
- **范例**：`examples/bluebook_shared_umbrella.py` 借伞 · The Shared Umbrella（软蓝雨天里的一张绘本跨页，背景蓝块毛边、不到纸边：左页是一个小小的公交站，玻璃候车亭里的长椅空着，只有一只蜗牛独占整条干燥的长椅，旁边是画着小巴士的圆站牌、亮着芥末黄灯的路灯，路灯下的大水洼里一只鸭妈妈带着两只小鸭玩得正欢；右页一个穿钴蓝雨衣、扎两个珊瑚红小揪揪的小女孩，双臂伸到最高，把一把珊瑚红小伞举向一只巨大、害羞、毛茸茸的白熊——伞只遮住了它的鼻子，雨落在它的耳朵和头顶，也落在小女孩自己的头发上，她一点也不在意，仰着头冲它笑；白熊低头看着自己并在一起的爪子，脸红了；水洼里映着一点红伞，蓝黑乱线的灌木里开着几朵珊瑚红小花；照绘本画家的顺序：空白纸、蓝色色块（天空块、雾里的远树、灌木、雨衣、候车亭、水洼）、松的墨线（线不闭合、偶尔描两遍）、乱线排出的暗部、珊瑚红点缀和点彩腮红、白粉笔（云、白毛、水纹、玻璃反光）、雨丝 / 水花 / 甩点 / 细尘，最后印在书上（中缝、页码、印刷的柔化）；`--stages` 出 7 个阶段加成品：空白纸、蓝色色块、墨线、暗部、点缀色、粉笔白、雨）
- **耗时**：约 5 秒
- **内部构成**：蓝调绘本（直方图均衡的纸纹与 8 个方向拖开的纸纹；毛笔 / 墨铅笔线：手抖、落笔收笔、粗细起伏、笔毛含墨、越画越干、顺笔的干白道、不闭合的轮廓与再描一遍；之字乱线暗部、平行短排线、草叶；干蜡笔 / 粉彩 / 干水粉上色：错位、游走的边、干边、笔道、纸纹白点、半透明混色，墨线始终在上；毛边、不到纸边的背景色块；白粉笔；雨丝、水花、水纹、甩点、细尘；大圆脑袋、点点眼、点彩腮红、雀斑、扇贝形毛边和白毛；印刷：柔化、抬黑、中缝、页码）

## 何时选用

温柔又好笑的小故事、绘本跨页或内页、童书封面和插页、「一个小角色帮另一个」这类有情节的一幕，下雨、下雪、夜晚这类安静的天气，要一眼就是「手画的现代绘本」，颜色只要一种主色（软蓝）加一点点睛色 → 蓝调绘本（要单人特写大头像、看得见毛衣针脚用复古水粉；要速写小卡上的针管笔线稿加淡彩用钢笔淡彩；要真的动起来的扁平小角色用绘本角色动画；要小孩自己画的蜡笔画用儿童蜡笔画；要网点和套色的观点插画用编辑风手绘）；

## 接口速查

```python
import sys; sys.path.insert(0, "<本skill>/lib")
from core import spline, curve, blob_pts, fbm1d, blur, polygon_mask  # 公共工具，按需取用
from bluebook import BlueBook
```

- 思路：照绘本画家的顺序画一页、再印出来（空白纸 → 蓝色色块 → 墨线 → 乱线暗部 → 点缀色和腮红 → 白粉笔 → 雨、水花、甩点 → 印刷）。
  - 纸纹：一张直方图均衡过的纸纹高度场 `T`（0–1 均匀分布），所以「工具碰到纸纹高于 1 − 接触压力的地方」直接就是覆盖率。另外预先算好沿 8 个方向拖开的纸纹 `TD`，每一笔按自己的方向取，干的工具漏掉的白点会顺着笔拉成短道。
  - 一笔（墨线、彩色蜡笔线、粉笔线、雨丝共用）：路径先过样条、按 2 px 重采样，再加慢的手抖和细颤。Pillow 把每段的序号画进 32 位整数图，得到这一笔覆盖的像素和所属线段，再精确投影出每个像素的弧长和横向偏移。
    - 落笔快、收笔慢（`taper`），沿途粗细起伏（`swell`）。
    - 横向几根笔毛含墨不同，沿笔越用越干（`dry`）；接触 × 含墨低于纸纹的地方断成顺着笔的白道。
    - 边缘随纸纹游走，不是矢量边。
  - 上色是干蜡笔、粉彩或干水粉：
    - 区域先整体错开 1.5–3.5 px（`slip`），边缘在模糊过的遮罩上用游走的阈值重新找（`loose`），靠边的地方压力减小、断成干边（`edge`、`dry_edge`）。
    - 覆盖率只由压力和纸纹决定（`pressure` 0.95 只留细白点）；颜色深浅由低频斑驳和平行笔道决定（`mottle`、`lanes`）。
    - 蜡和粉彩半透明：新 = 旧 + (色 × 旧^0.55 − 旧) × 覆盖。盖在白纸上就是本色，盖在墨上仍是黑，蓝上加蓝更深；`medium='gouache'` 和 `'chalk'` 不透明。
  - 墨在上：墨的覆盖记在 `K` 里，之后再上的颜色在墨上几乎挂不住（`over_ink` 默认 0.1，粉笔 0.5，眼睛高光 1），所以线一直在颜色上面，像印出来的书。
  - 最后 `printed()`：印刷的轻微柔化、只把黑抬到深墨色（白纸不变灰）、细纸点，可选中缝（柔和的阴影、一道细折痕和一线亮边）。
- 构造：`BlueBook(W, H, seed, keep_stages=True, stages_dir=None)`（总像素不超过 4096²），先 `paper(tone='paper', tooth, drag)`。坐标是整张画布的像素。
- 形状：返回画布大小的浮点遮罩，用 `np.maximum`、相乘、`1 −` 组合。
  - `ellipse(cx, cy, rx, ry, rot)`、`poly(pts, smooth=True)`、`blob(cx, cy, rx, ry, rough, seed, rot)`、`band(path, w0, w1)`；`BlueBook.tube(path, w0, w1)` 给轮廓点。
  - `cloud(cx, cy, w, h, bumps, seed)` 云；`rect(x0, y0, x1, y1, rough, corner, seed)` 手画的毛边矩形。
- 颜色：
  - `block(box 或遮罩, colour='powder', rough, corner, pressure, angle, edge, dry_edge, streaks, avoid, halo)` 背景大色块：毛边、不到纸边，边缘的笔道顺着边走、拖干，再贴着边拖几十笔干笔（限在边缘附近）。
  - `fill(mask, colour, pressure=0.9, angle, slip, loose, edge, dry_edge, mottle, lanes, lane_var, passes, medium='crayon'|'gouache'|'chalk', avoid, halo, clip, streak, over_ink)` 涂一块，返回实际涂到的区域。`angle` 是数或画布大小的角度场；`avoid` + `halo` 绕开前面的东西、留一圈白缝；`slip=0` 不错位。
  - `crayon(paths, colour, width, pressure, dry, medium)` 沿路径的彩色干笔（头发丝、远树干、湿地面、倒影）。
- 墨：
  - `ink(path, width=4, dry, taper, wobble, swell, overshoot, clip)` 一笔毛笔 / 墨铅笔线。
  - `outline(pts, width, closed=True, open_=0.45, overshoot, strokes=(1, 3), twice=0.35)` 快速的轮廓：闭合形分 1–3 笔，在接头前停下留缺口，或冲过接头顺着切线出头；`twice` 是某一段再描一遍、偏开一两 px 的几率。
  - `scribble(mask, width=5, spacing=4.5, angle=80, reach, overshoot, dry, colour, clip)` 暗部：沿一个方向来回不抬笔的之字乱线，转折处冲出或不到轮廓，一次一个手腕的范围。
  - `hatch(mask, angle, spacing, length, width, colour, medium, density)` 一根根平行的快速短排线（衣服暗面、白毛的阴影）。
  - `blades(x0, x1, y 或 f(x), n, height, lean, width, clip)` 从底线长出来的锥形草叶。
  - `dot(x, y, r, ry, colour, medium)` 边缘不规则的实心小点（眼睛、鼻子、扣子）。
- 白与天气：
  - `chalk(遮罩 或 路径列表, width, pressure=0.62, angle, over_ink=0.5)` 不透明的白粉笔 / 白粉彩：给遮罩就涂（云、小巴士），给路径就画（高光、玻璃反光），只挂在纸纹凸起上，顺着笔拉成长道。
  - `rain(region, n, angle=100, length, width, colour='deep', avoid)` 短的干笔雨丝。
  - `splash(x, y, size, colour, n, up)` 雨点落下溅起的一圈小短线和水珠；`ripples(cx, cy, rx, ry, rings)` 水洼上断开的同心圈。
  - `spatter(region, colour, n, size, satellites)` 甩出来的颜料点（幂律大小、略拉长、带小卫星点）；`speckle(region, colour, n, size)` 更细的尘点和闪点。`region` 是遮罩或 (x0, y0, x1, y1)。
- 角色：
  - `head(cx, cy, rx, ry, width, ears=[(x, y, r)])` 大圆脑袋的开口轮廓，耳朵只画露出来的那段，返回头（含耳朵）的遮罩。
  - `eyes(pts, r, look=(dx, dy), glint)` 带白高光的点点眼；`smile(x, y, w, depth, tilt)`；`blush(cx, cy, r)` 点彩腮红（一层很淡的蜡笔底 + 稀疏的粉点）；`freckles(cx, cy, n, spread)`。
  - `fluff(mask, 'ink' 或 'chalk', length, width, curl, avoid, gaps, curls, reach)` 毛绒。`'ink'` 把轮廓画成一串短的扇贝形小弧（不闭合，有缺口）；`'chalk'` 是从里往外越过边缘、压在背景蓝上的白毛；`curls` 是里面的小卷。
  - `flower(x, y, r, colour='coral')` 小花：不透明的花瓣加墨点花心。
- 收尾：`printed(amount, gutter=x)` 印在书上；`folio(x, y, '14', size)` 小页码；`render()`、`composite()`、`stage(name)`、`save(path, stages_dir)`；`save('x.jpg')` 默认 quality 88、4:4:4 色度。
- 颜色用 `COLOURS` 里的名字（paper chalk ink mist powder cornflower blue cobalt deep teal navy slate coral tomato cheek flesh freckle mustard butter）或 '#rrggbb'；常量 `COLOURS`、`INK`。

## 毛病清单（都真实出现过）

| 问题 | 改法 |
|---|---|
| 背景蓝块里白道太多，像刮花的粉笔 | 压力的斑驳和笔道直接改了覆盖率，压力掉到 0.7 就露出三成白纸：覆盖率只由 `pressure`（0.95 左右）和纸纹决定，斑驳和笔道只改颜料浓淡；纸纹只一半顺笔拖开（`streak` 0.45），里面只剩细白点 |
| 白纸发灰发脏 | 纸纹在白纸上的明暗 0.022 → 0.012，印刷细点 0.016 → 0.009；纸色改成更白的 #fbfaf5 |
| 墨点像带刺的墨团 | 点的半径每个顶点单独随机：改成沿一圈的低频起伏 |
| 熊的毛边是碎碎的虚线 | 小弧太短太干：长 16–30 px，间隔为平均长度的 0.62 倍（相邻小弧叠一点），dry 0.12，12% 的位置留缺口 |
| 珊瑚红小花、伞的倒影在深色上发褐 | 蜡的半透明混色（色 × 底^0.55）盖在深青、蓝上会变暗：深底上的点缀用不透明的 `medium='gouache'`（倒影 alpha 0.8）；伞、头发这些大块在背景色块里先留白（`avoid`），蜡笔涂在白纸上 |
| 后上的颜色把墨线盖掉，眼睛的白高光不见了 | 墨的覆盖记进 `K`，之后上的颜色乘 (1 − 0.9·K)；高光 `over_ink=1`，粉笔 0.5 |
| 举伞的胳膊从小孩脸上横穿过去 | 两只胳膊都从右肩出发，在头的右侧往上伸：先确认胳膊在头的高度上 x 大于头的右边缘 |
| 草叶和乱线画到了熊腿和小孩身上，靴子是白的、只有几道灰线 | `blades`、`scribble` 加 `clip=1 − 前景遮罩`；小面积的靴子先用近黑的不透明水粉涂满，再在上面乱线 |
| 熊整只发灰发蓝 | 暗面的淡蓝、排线和落在熊身上的雨都太多：暗面只留最右边一窄条，排线行距 14–16、density 0.6–0.7，熊身上只下 45 笔雨，用粉蓝 |
| 熊的鼻子在伞边上，不像「只有鼻子是干的」 | 口鼻往左拉长（rx 80 → 92），鼻子挪到伞的雨影正中；雨按斜度留出伞下一条不下雨的柱子，熊的头顶、耳朵加水花和挂着的水珠 |
| 乱线暗部是一把梳子、一条黑带横贯整页 | 暗部遮罩的上缘是一条直线，转折全排在一条线上：改成按「越往下越暗 + 低频噪声」取阈值的一团一团（深青灌木 0.66、蓝灌木 0.9），笔 5.2 px、行距 4.6 px 叠成一片；蓝灌木用藏青不用黑；灌木底线改成波浪 |
| 蜗牛读成长椅靠背上的一个芥末黄圆盘 | 去掉靠背；候车亭里加一块淡蓝玻璃（不透明水粉，alpha 0.82），蜗牛坐在座板上，眼柄和小笑脸落在浅色玻璃前面才看得见 |
| 远处的树是一个个平涂的气球 | 改小、颜色改成接近天色的 #a3c1e2、两团叠成不规则的树冠，加竖向的干笔树干；小孩身后那棵删掉，免得像她头后面的气球 |
| 线条像马克笔，太细太匀 | 主要轮廓加粗约 20%（小孩头 5.2、熊毛边 4.2、伞 4.8），`swell` 0.3–0.35；`outline` 默认 35% 的几率把一段再描一遍、偏开 1.5–3 px |
| 雨像数码雨，一样长、一样密 | 深蓝 560 笔（10–40 px）、矢车菊蓝 260 笔、粉笔白 240 笔，三种深浅、长短拉开 |
| 鸭妈妈的头伸进天空色块，染成了蓝 | 鸭子放低，并加进背景色块的 `avoid` |
| 背景块角上一道干笔斜着戳出纸外 | 贴边的干笔用 `clip` 限在块的边缘附近 |
| 印刷一步把白纸压灰，动图最后一帧整体一暗 | 「黑色抬到墨色」原来是整体混进 5% 深墨：改成 c0 + 颜色 × (1 − c0)，白纸不动，只抬黑 |
