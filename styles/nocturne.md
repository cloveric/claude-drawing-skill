# 排线夜景（nocturne）

- **实现**：`lib/nocturne.py` · `Nocturne`
- **范例**：`examples/nocturne_lava_sea.py` 熔岩入海 · Lava Meets the Sea（一张装在米白纸边里的 16:9 小幅夜景版画：黎明前的火山海岸，熔岩从深色的火山坡上一缕缕淌下来，蜿蜒、分股，到海边散成一片细流，流进海里的地方是全画唯一的暖光——海水被激成蒸汽，一柱云团往上翻、顺风往左歪，从下往上被照亮：水边黄白，往上橙红，再往上是暖灰，到顶上是冷的石板蓝；火星往上飞，坡上几处停住的熔岩前锋还亮着小珠；海面上一条被横向笔触打碎的暖色光柱一直拉到画面底边，云团的红光也碎碎地映在水里；远处一座低矮的岛，海中间的一块小礁石上坐着两个看它的人（四十来像素高），其中一个围着红围巾；靛蓝的天空顺着风斜着流，零星几颗星；天、云、山、海全是顺着各自方向的短笔触，每笔色相明度都差一点，留着底色的细缝；画心外一道压印的版痕，左下铅笔小字「Forty seconds」，右下更小的「lava meeting the sea before dawn」；照画家的顺序画：纸和深色底、天空、远岛和火山、冷色的蒸汽、亮光（被照亮的云、天空和山坡上的光笔触、热源）、熔岩细流和火星、海、倒影、礁石和小人、装裱和题字；`--stages` 出 9 个阶段加成品）
- **耗时**：约 9 秒
- **内部构成**：排线夜景（直方图均衡的纸纹与沿 8 个方向拖开的纸纹；在方向场里积分出中心线的短笔触：落笔钝、收笔尖、带一点弯；id 图光栅化：Pillow 按序号填轮廓、2 倍超采样，numpy 逐像素查回这一笔的位置和方向，算出沿笔 / 横向坐标、6 道笔毛的深浅与含量、越往笔尾越干、颜料只落在纸纹低于压力处；每笔的明度抖动和绕灰轴的色相旋转；风向、放射、等高线方向场与双倍角混合；点光源和发光遮罩合成光照图，加光（screen）或「光 × 受光」上色的光笔触，暖白化；放射笔触的热源；带惯性游走的蜿蜒细流、分股、支流、结壳的亮度和前锋亮珠，2 倍浮点发光缓冲与紧贴的光晕；抛物线火星、零星火星、星点；镜像取样的碎倒影、光柱；笔触画的剪影和朝光轮廓光、几十像素高的坐着的小人和围巾；米白纸边、纤维、胶带边、压印版痕、细体铅笔小字；画心内的克制辉光、细颗粒）

## 何时选用

夜里的一个瞬间：一处火光、闪电、极光、篝火、渔火、熔岩、烟花，配一大片深蓝的天和水，要一眼就是「手画的小幅版画」、有满画面的笔触感和一点孤独，讲解片里的「一个极短的瞬间」「远处发生的大事」「自然现象」页，文章配图和海报 → 排线夜景（要梵高式厚涂漩涡和颜料浮雕用油画厚涂；要粉彩黄昏转入银河、满坡野花用暮色微缩绘本；要霓虹雨夜街道用赛博朋克；要黑白石墨排线用铅笔素描；要明亮可爱的彩铅小物用韩国彩铅）；

## 接口速查

```python
import sys; sys.path.insert(0, "<本skill>/lib")
from core import spline, curve, blob_pts, fbm1d, blur, polygon_mask  # 公共工具，按需取用
from nocturne import Nocturne
```

- 思路：照粉彩 / 彩铅画家的顺序画一张小幅夜景（纸和深色底 → 天空 → 远处的陆地 → 冷色的云 → 加光 → 发光的细丝和火星 → 海 → 倒影 → 小人 → 装裱和题字），整张画只由一笔一笔的短笔触组成，暖光是最后一层层「加」上去的笔触。
  - 纸：直方图均衡过的纸纹 `T`（0–1 均匀分布）、低频斑驳和几百根纤维；画心先铺一层深色底，以后每一笔都裁在画心里（像贴了胶带），纸边始终干净。另外预先算好沿 8 个方向拖开的纸纹，每一笔按自己的方向取，漏掉的纸纹顺着笔拉成短道，不是孤立的黑点。
  - 一笔：中心线在一个方向场里积分出来（方向按 mod π 处理，一笔中途不会掉头），再带一点弯，落笔钝、收笔尖。几万笔一次画完：Pillow 把每一笔的轮廓按序号填进 2 倍超采样的整数 id 图（后画的盖住先画的），numpy 对每个像素查出那一笔的颜色、起点、方向、长和宽，算出像素在笔上的位置（沿笔 u、横向 v），由 v 得到笔毛道：每笔 6 道，各有自己的深浅和含量，越往笔尾越干（`dry`），颜料只落在纸纹低于压力的地方（`pressure`），所以每一笔都有笔毛条纹和颗粒，深色的底从细缝里透出来；再缩回 1 倍。同一批里最上面那笔说了算（不会糊成一团），层次靠多遍叠。
  - 颜色：一笔取一个颜色——一个颜料、一条色阶按明度场取，或任意 f(x, y)；再加每笔自己的明度抖动（`value`）和色相抖动（`hue`，绕灰轴真正转色相）；`lit` 把光照图加到笔上，所以光里的笔触本身是暖的。
  - 方向场：`flow(角度, 扰动, 尺度)` 整片的风向；`radial(cx, cy)` 从一点放射（锥形山的坡向、光的放射）；`contour(密度)` 顺着等高线（绕着云团、沿着山脊）；`blend(f1, f2, w)` 用双倍角混合（0 和 π 是同一个方向）。云团里的笔顺着上升的柱子走，只在团边上绕着卷，处处都绕会卷成漩涡。
  - 光：`light()` 点光源、`light_from()` 发光的遮罩（熔岩细流）合成一张光照图。`glow()` 铺光笔触：落笔的概率跟着「光 × 受光」走、颜色取光照图，所以光是越往外越稀的暖色笔触，不是一团平滑的光晕。空气和眩光用加光（screen）；被照亮的表面用 `blend='paint'` 按「光 × 受光」直接上色——蓝灰的云加上橙光会变粉，直接画成被照亮的颜色才是红橙；`whiten` 让离热源最近的那些笔偏向暖白（白色的蒸汽）。
  - 热源 `source()`：一小撮黄白的笔、一圈圈往外放射的橙、红笔触，一个很小的白芯和很小的辉光。
  - 细丝：`threads()` 是带惯性、一直转向终点（并顺着坡离开山顶）的游走，所以是蜿蜒的细流不是折线闪电；分股的细丝越往末端分得越开，小角度的支流分出去后渐隐或停在一颗亮珠上，亮度一段段有结壳的暗处，前锋最热。`filaments()` 把它们画进 2 倍浮点发光缓冲：细线、紧贴的光晕、照到旁边东西上的光笔触、末端和沿途的亮珠。`sparks()` 是抛物线飞出的火星：一小段渐淡的拖尾和一个热的头。
  - 水：`reflect()` 在海面上铺横向笔触，颜色取水线以上画面的镜像（被浪拉长、被涟漪横推、压暗并混进海色），只在镜像亮的地方落笔，所以倒影是碎的；`glitter()` 是水线上的光源朝观者拉出的光柱：近处热而窄，往下变宽、变红、更碎。
  - 小人和剪影：`figure()` 是几十像素高的坐着的小人（头、躯干、屈起的腿、搭在膝上的手），剪影色，一点亮色（围巾、帽子），朝光的一侧一道暖色轮廓光；`silhouette()` 用笔触画深色的块（礁石、岛、山），可选朝光一侧的轮廓光。
  - 装裱：`mount()` 在画心外压一道版痕（凹槽的上沿和左沿暗、下沿和右沿亮）；`caption()` 用细的普通字体（Helvetica Neue Light / Thin 一类，不用手写体）逐字写铅笔小字，基线和角度有一点点抖，石墨在纸纹上发虚。收尾 `bloom()` 只给画心里最亮的光一点克制的辉光，`grain()` 细颗粒。
- 构造：`Nocturne(W, H, seed, keep_stages=True, stages_dir=None)`（总像素不超过 4096²），先 `sheet(box=(x0, y0, x1, y1), paper, ground)`。坐标是整张画布的像素；方向场是弧度，`flow()` 的角度用度（屏幕 y 朝下，正角度向右下斜）。
- 遮罩：`poly(pts, smooth)`、`ellipse(cx, cy, rx, ry, rot)`、`blob(cx, cy, rx, ry, rough)`、`below(xs, ys, invert)`（一条样条线以下）返回画布大小的浮点遮罩；`value(top, bottom, y0, y1, mottle, scale)` 竖向明度场加低频斑驳。
- 笔触：`hatch(region, field, colour, length, width, density, jitter, bend, value, hue, alpha, pressure, dry, lanes, lit, mode='paint'|'light', taper, clip)`。`region` 是落笔概率遮罩或 (x0, y0, x1, y1)；`density` 约等于把区域铺几遍；`length` / `width` 给 (最小, 最大)、一个数或 f(x, y)（海面越近越长）；`colour` 给颜料、(色阶, 明度场或 f(x, y)) 或 f(x, y) → (N, 3)。
- 光：`light(x, y, r, colour, power, squash)`、`light_from(emission, spread, colour, power)`、`lightmap()`；`glow(receptivity, field, length, width, density, power, reach, blend='light'|'paint', ambient, whiten)`；`source(x, y, r, power, field, squash, core)`。
- 细丝和点：`threads(start, ends, wander, strands, spread, branches, branch_len, width, fall, heat)` 返回路径；`filaments(paths, gain, halo, light, receptivity, field, beads)`；`sparks(x, y, n, spread, speed, streak)`；`embers(region, n)`；`stars(region, n, size, bright)`。
- 水：`reflect(waterline, region, src, stretch, ripple, darken, mixw, thr, length, width, density)`（`src` 传画海之前的画布，`waterline` 可以是逐列的数组）；`glitter(x, y_water, y_end, w0, w1, power)`。
- 剪影和小人：`silhouette(mask, ramp_, field, val, density, rim, rim_from)`；`figure(x, y, h, facing, accent, accent2, legs='knees'|'dangle', lean, rim_from, rim, hat)` 返回小人的遮罩。
- 收尾：`mount(plate, depth)`、`caption(text, x, y, size, anchor, weight='light'|'thin', alpha, jitter)`、`bloom(amount)`、`grain(amount)`；`render()`、`composite()`、`stage(name)`、`save(path, stages_dir)`；`save('x.jpg')` 默认 quality 88、4:4:4 色度。
- 颜色用 `PAINTS` 里的名字（paper pencil ground night indigo navy dusk haze starlight mist slate steam steam_lit rock rock_lit sea sea_deep glint blood ember lava flame core scarf star warmstar）或 '#rrggbb'；色阶用 `RAMPS` 里的名字（fire ember sky sea steam land isle）或自己给一串颜色。

## 毛病清单（都真实出现过）

| 问题 | 改法 |
|---|---|
| 云团里一圈圈同心的漩涡，像梵高的星空 | 笔触处处沿团块的切线走：团块里面改成顺着上升柱子的方向（顶上顺着风），只在团块边缘（半径 0.55–0.97）混进切线，最多 0.75 |
| 海面和云里满是孤立的黑点，像脏了 | 纸纹缝隙是一个个孤立像素，深色的底从里面透出来：纸纹沿 8 个方向拖开，每笔按自己的方向取，漏白顺着笔成短道；默认压力 0.9 → 0.95，海面、倒影 0.96–0.975；底色从 #0a0f27 提到 #0d1331 |
| 熔岩细流像一道道闪电劈向海面 | 直线段加大角度的分叉、黄白色：改成带惯性的游走（一直转向终点、顺坡离开山顶），支流只分 0.18–0.5 弧度；发光的颜色在色阶上压到 0.3–0.92（主要是橙红），只有亮珠和前锋发黄 |
| 改成游走后细流打圈、像一团意面 | 转向噪声太大、拉向终点太弱：每步转角 0.035·wander（0.85 衰减），拉力 0.16–0.46 |
| 熔岩入海处是一个平滑的大白团，像爆炸 | 光改成一圈圈放射的笔触（黄白 → 橙 → 红，色阶起点 0.28–0.72）；平滑的白芯缩到 0.11 r、辉光 0.18；横向压扁（0.6）；沿入海的一排细流再放两个小热源 |
| 被照亮的云是一片鲑鱼粉 | 橙光用 screen 加到蓝灰的云上就是粉：受光的云改用 `glow(blend='paint')`，颜色 = 光 × 受光 + 一点暗的环境色，才是红橙；另一层很淡的加光只给最亮的底部 |
| 云柱底部像一丛火苗 | 往上走的长笔触、饱和的黄橙、中间的暗缝：近热源的笔 `whiten` 0.6 偏暖白（蒸汽是白的），底部的小团块多混一点切线（卷起来），亮笔触压力 0.97、密度 1.8 |
| 天空的浅色短笔像在下雪 | 浅色笔触太多、太亮、太短：只落在噪声的高处（成片成带），密度 0.35 → 0.16，长 18–42、宽 1.1–1.7，明度只比底色高 0.3 |
| 天空是饱和的宝蓝，不是夜色 | 天和海的色阶整体压暗、去饱和，往靛蓝和冷灰蓝靠；天顶明度 0.04、地平线 0.6 |
| 倒影两侧边缘一道道白横线 | 镜像取样被涟漪推到了画心外的米白纸边：取样坐标限制在画心里 |
| 礁石上一块块橙红，像也有熔岩 | 礁石离热源远，轮廓光太强：rim 0.9 → 0.14；小人的轮廓光 0.45 |
| 版痕的线一直延伸到纸的边上 | 用的是到四条无限长直线的距离：改成到矩形的距离，上沿和左沿的暗线也只在矩形范围内 |
| 成品一步画心边缘多了一圈褐色 | 辉光把画心外米白纸边的亮度也模糊进来了：辉光只取画心里的亮度 |
| 远处的岛看不见 | 太矮、颜色和地平线的天一样：岛加高 10–15 px，改用最暗的陆地色阶 |
| 两个小人在深色海面上看不出来 | 他们身后加一小片浅色波光（横向短笔，只在礁石外），剪影才立起来；小人 40–44 px，围巾是唯一的亮色 |
| 熔岩路径有 NaN | float32 里 sin(π) 是一个很小的负数，`** 0.8` 得到 NaN：先 clip 到 0–1 |
